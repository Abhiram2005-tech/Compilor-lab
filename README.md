# Compiler Lab (`Compilor-lab`)

Welcome to the **Compiler Lab** repository. This project is dedicated to implementing various phases of a compiler, starting with lexical analysis. It serves as a practical guide and codebase for understanding how programming languages are parsed, analyzed, and translated.

---

## 🚀 Features

* **Lexical Analysis (`lex.c`):** Tokenizes input source code into meaningful components such as keywords, identifiers, operators, and constants.
* **Clean Structure:** Minimalist and straightforward C-based implementation, perfect for educational purposes and lab assignments.
